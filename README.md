# Gaurav Shandilya — Portfolio

Personal portfolio: experience, skills, personal projects and open-source work. Live at [pure-folio.vercel.app](https://pure-folio.vercel.app).

**Stack:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, next-themes.

```bash
npm install
npm run dev    # http://localhost:3000
npm run build
```

Content lives in `src/lib/config.ts` (links) and the section components in `src/components/`. The resume is served from `public/resume.pdf`.
